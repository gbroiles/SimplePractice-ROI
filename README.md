# SimplePractice - Release of Information

Template generator for release of information to be used with Simple Practice to create a customized Release of
Information form to be signed electronically within the Client Portal.

The file is intended to be stored on a user's local computer or served from a user-controlled webserver.
All processing occurs on the user's local computer and no information is sent to any other computer. The user can
choose to save the generated text as a .txt file or copy it to the clipboard to be pasted into Simple Practice.

The template must be customized by editing the line beginning with 
"I, [Name of client], hereby authorize `[Provider: Provider Name]`" (currently line 147) and changing the 
`Provider Name` text to reflect the actual practitioner name. (Example - `[Provider: Sigmund Freud]`)
Alternately, if the bracketed text is just `[Provider]`, no default text will be present in that field. 

The text can otherwise be edited to suit the user's needs. Items can be added or removed from the `[Checkboxes]`
entry as desired. 

To use the generated template, inside Simple Practice select *Settings* then *Documentation* then *Shareable Documents*.
In the *Consent Forms* section, select *New consent form* at the bottom. A window will open with a single-line field
for the name of the template. I suggest using the client's initials because the template is individually customized
per client) - something like "JFK Release." Click *Copy to Clipboard* in the generator window, then click into the
multi-line text field in the Simple Practice window and paste the contents of the clipboard. Click the *Save* button.

Now, go to the *Clients and contacts* tab, click on the client's name, choose the *Files* tab, pull down the *Actions*
tab, choose *Share items*, select the template that was just created, then *Continue to Email* and *Review & send*
as you would with any other consent form. The customized form will be sent to the client for their electronic
signature. 

Once the consent form has been created in Simple Practice, the browser window with the generator form may be closed.
Nothing will be saved to disk or sent over the network except at the direction of the generator's user. For best
privacy, ensure that any browser cache that may be present is cleared if PHI was used in the creation of the form.
